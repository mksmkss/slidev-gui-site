Slidev GUI 入手する

見たまま直せて、中身はテキスト。

Slidev GUI は、PowerPoint と同じように画面の上でスライドを作れるエディタです。保存されるのは 1 つのテキストファイルなので、変更の履歴が読め、AI にもそのまま渡せます。

PowerPoint にない 12 の操作

保存されるのは、読めるテキスト

1 枚のスライドは数行のテキストです。置いた位置も「幅 1/2、左から 47%」のように、読める形で入ります。

要素を動かすと、変わるのはその 1 行だけ。ほかの行には触れません。

# 貸出の傾向平日は夕方、休日は午前に集中する。<div class="absolute w-1/2 left-[47%] top-[22%]"><HighlightText variant="red">雨の日は 2 割増える</HighlightText></div>

ほかにできること

テーマの部品
章の扉、ヘッダー、注意書き、数式、引用。テーマ gtlabo の部品を、名前で呼んで置けます。
AI に頼む
手元の Claude Code に文で頼めます。変更前と変更後を見比べてから、適用するかを決めます。
Git で同期
ボタン 1 つで、記録して、相手の変更を取り込み、送ります。
書き出し
PDF、PowerPoint（PPTX）、画像（PNG）に書き出せます。
今ある Slidev のフォルダ
そのまま開けます。何も直さずに保存しても、ファイルは 1 文字も変わりません。
